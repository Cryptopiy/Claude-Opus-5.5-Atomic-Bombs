## English

### Claude Opus 5.5 — Atomic Bombs: 20 historical bombs from a desert bunker (Godot)

From the **Atomic Bombs** video: Claude Opus 5.5 built a Godot observation sim — from a concrete bunker on a test range you set off 20 historical bombs in order of yield, from a Mk 82 to the Tsar Bomba: flash, fireball, shock wave and mushroom cloud based on real physics, with the sound arriving late. Educational project.
